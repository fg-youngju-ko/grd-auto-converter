재고 파일을 선택하고 변환을 시작하세요

grd_list00_YYYYMMDDHHMMSS.xls 형식

사용 방법

  1. 재고 파일(grd_list00_*.xls)을 선택합니다. (필수)
  2. 관리 품목 코드는 브라우저에 영구 저장됩니다. 🏷️ 코드 관리에서 코드를 추가·삭제하거나, 📋 파일로 추가로 txt/csv 파일(한 줄에 코드 하나)의 코드를 한번에 담을 수 있습니다. 등록된 코드의 품목 행은 파란색으로 강조됩니다. (선택)
  3. 변환 시작을 누르면 예량 계산과 색상 서식이 적용된 표가 화면에 표시됩니다.
  4. 표가 만족스러우면 xlsx 다운로드로 결과 파일을 저장합니다.

표 사용 팁

  • 날짜별 출예/물입예/계획/예량/기타 열의 헤더를 클릭하면 그 열만 필터됩니다. (물입예는 0이 아닌 값, 나머지는 음수만)
  • 필터 바의 음수 행만 / 입잔 양수만 / 관리 품목만 토글과 재고구분·품목코드/단품명칭 검색으로 행을 좁힐 수 있습니다.
  • 표 맨 아래 합계 행은 현재 화면에 표시 중인 행만 기준으로 자동 계산됩니다.
  • 행에 마우스를 올리면 굵은 테두리로 해당 행이 강조됩니다.
  • 품목코드·단품명칭 셀을 클릭하면 클립보드로 복사됩니다.
  • 셀에서 마우스 우클릭하면 메모를 입력할 수 있고, 메모가 있는 셀은 우측 상단에 빨간 표시가 붙어 마우스를 올리면 내용이 보입니다.
  • 변환 결과와 메모는 브라우저에 4시간 동안 자동 저장되어 창을 닫았다 열어도 이어서 볼 수 있습니다. 전체 초기화 버튼으로 언제든 완전히 삭제할 수 있습니다.
